Red vs Blue Button Question Analysis

A tool for analyzing the viral red vs blue button discourse through some lesser considered parameters

Blue wins any unresolved case. Turn this off to make red the default priority.
When enabled, a gray middle band appears in the vote slider and the third rule button unlocks.
If Threshold Pass is selected, in the event that both sides reach the threshold, the priority side wins by default. If More Votes Wins is selected, in that same event the higher number of votes will win.
